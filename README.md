# NeXtep

## English

NeXtep is an open-source Xposed module providing a multi-app workspace for Android 16 / ColorOS 16.

### Demo video

[Watch the NeXtep demo on Bilibili](https://www.bilibili.com/video/BV1mPYd6XEU8/)

### Features

- A main app area, three side app slots, and a top control area
- Switching apps between workspace slots and full screen
- Preserving the workspace across screen locking and unlocking
- Customizable top content: icon, time, date and weekday, custom text, or blank
- Adjustable frosted-glass backgrounds

### Requirements

- Android 16 / ColorOS 16
- Root access
- Zygisk and LSPosed installed
- Primarily tested on OnePlus PLK110

### Installation

1. Download and install the APK from this repository's Releases.
2. Enable NeXtep in LSPosed.
3. Select the required module scope.
4. Restart the device.

[Source code and detailed documentation](https://github.com/lujinxin/NeXtep)

## 中文

NeXtep 是一款适用于 Android 16 / ColorOS 16 的开源 Xposed 模块，提供多应用工作区。

### 演示视频

[在哔哩哔哩观看 NeXtep 演示视频](https://www.bilibili.com/video/BV1mPYd6XEU8/)

### 功能

- 主应用区域、三个侧边小窗和顶部控制区域
- 小窗与全屏之间的应用切换
- 锁屏并解锁后保留工作区
- 顶部可显示图标、时间、日期与星期、自定义文本或留空
- 可调节强度的磨砂玻璃背景

### 使用要求

- Android 16 / ColorOS 16
- Root 权限
- 已安装 Zygisk 和 LSPosed
- 当前主要在 OnePlus PLK110 上测试

### 安装方法

1. 从本仓库的 Releases 下载并安装 APK。
2. 在 LSPosed 中启用 NeXtep。
3. 按模块要求选择作用域。
4. 重启设备。

[源码与详细使用说明](https://github.com/lujinxin/NeXtep)
